# Octria

A free, cross-platform app that turns any task into a classroom with a roadmap of phases and steps, shown as an interactive node graph called Flowspace.

Phase 1 is complete: the Flowspace prototype, running on sample data. Sign-in, real classrooms, Kanvas and the Ofy AI come in later phases.

## Run it

Needs [Flutter](https://flutter.dev).

```bash
flutter pub get
flutter run
```

```bash
flutter test
```
